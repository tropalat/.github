# Tropa

Signed, verifiable health records for cattle, from the vet's prescription
to the export certificate. Built in Uruguay, on top of the country's
individual animal traceability.

Registros sanitarios firmados y verificables para ganado, desde la receta
del veterinario hasta el certificado de exportación.

## What is public here

- **[roots](https://github.com/tropalat/roots)**: the daily Merkle root of
  every event recorded in Tropa, anchored with OpenTimestamps.
- **[verify](https://github.com/tropalat/verify)**: a command-line tool to
  check a Tropa document or evidence pack without trusting Tropa.

## Status

In development. Pilot planned for early 2027 in Uruguay.
